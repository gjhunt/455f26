## Text

There is no required book for this course. The primary written reference is the [course notes website](https://gjhunt.github.io/ml/), which contains the notebooks corresponding to the material covered in lecture.

The following two books are useful supplemental references. They are standard books in the field and recommended, but not required.

1. *The Elements of Statistical Learning* by Hastie, Tibshirani, and Friedman: [https://web.stanford.edu/~hastie/ElemStatLearn/](https://web.stanford.edu/~hastie/ElemStatLearn/)

   This is an advanced undergraduate/masters-level book. The course overlaps with many of its topics, and the book is freely available online.

2. *An Introduction to Statistical Learning, with Applications in R* by James, Witten, Hastie, and Tibshirani: [https://www.statlearning.com/](https://www.statlearning.com/)

   This is a more undergraduate-friendly text and is also freely available online.

## Python Preparation and Optional DataCamp Practice

Programming examples in lecture will use Python. Students are expected to enter the course with basic proficiency in Python programming. In particular, you should be comfortable working with variables and basic data structures, writing and using functions, using loops and conditional statements, and reading and modifying existing Python code. Familiarity with NumPy and pandas will also be useful.

This course is not intended to teach introductory Python programming. Students who are rusty with Python should spend some time reviewing before or during the first week of class.

Useful refresher resources include:

* **[DataCamp: Introduction to Python](https://www.datacamp.com/courses/intro-to-python-for-data-science)** - a short interactive review of basic Python syntax, data types, lists, functions, and NumPy.

* **[The Official Python Tutorial](https://docs.python.org/3/tutorial/)** - a useful reference and refresher for core Python syntax and programming concepts.

* **[NumPy: The Absolute Basics for Beginners](https://numpy.org/doc/stable/user/absolute_beginners.html)** - a review of arrays, indexing, and numerical computation with NumPy.

* **[pandas Getting Started Tutorials](https://pandas.pydata.org/pandas-docs/stable/getting_started/intro_tutorials/index.html)** - a review of DataFrames and basic data manipulation.

Optional DataCamp exercises may be posted throughout the course to provide additional practice with Python and course concepts. These exercises are not required and will not count toward the final grade. Students are encouraged to use them as supplemental practice, particularly when additional experience with the programming material would be helpful.
